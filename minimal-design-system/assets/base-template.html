About

This template demonstrates the core patterns of the Minimal Design System v2.0. It uses HSL-based color tokens for flexibility and semantic naming for maintainability.

The design philosophy centers on generous whitespace, clear typography hierarchy, and automatic light/dark mode switching via prefers-color-scheme.
